# Browser Extension Installer (Double-click to install)
# Or drag to Chrome Extensions page

# Chrome/Edge Extension Installation Instructions:

## Manual Installation:
1. Open Chrome/Edge
2. Go to Extensions (chrome://extensions/ or edge://extensions/)
3. Enable "Developer mode" (toggle in top right)
4. Click "Load unpacked extension"
5. Select this folder (containing manifest.json)
6. Enable the extension

## Alternative - Packed Installation:
1. Open Chrome/Edge
2. Go to Extensions page
3. Enable "Developer mode"
4. Click "Pack extension"
5. Select this folder as root directory
6. Upload the resulting .crx file

## Firefox Installation:
1. Open Firefox
2. Go to about:debugging
3. Click "This Firefox"
4. Click "Load Temporary Add-on"
5. Select manifest.json file

## After Installation:
✅ Extension will automatically start when you visit Guacamole pages
✅ Local print agent must be running (node server/websocket-server.js)
✅ Look for the print button in the top-right corner of Guacamole pages

## Requirements:
- Chrome 88+ / Edge 88+ / Firefox 89+
- Local print agent running on localhost:8181
- Guacamole web interface access

## Features:
- 🖨️ Print files directly to local printers
- 💾 Save files to local storage
- 📊 7-day print history tracking
- 🔗 Real-time WebSocket communication
- 🎨 Modern responsive UI
- 🌐 Works with all Guacamole file types
