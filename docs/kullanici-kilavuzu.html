1. Genel Bakis

Guacamole Yazici Ajan, Apache Guacamole uzerinden actiginiz uzak masaustu (RDP) oturumlarindan yerel yaziciya yazdirma ve dosya indirme islemlerini kolaylastiran bir yazilimdir.

Sistem su sekilde calisir:

Uzak Masaustu (RDP Oturumu) | v Guacamole Web Arayuzu (Tarayici) | | Dosya / yazdir komutu algilanir | JavaScript otomatik yakalar v WebSocket (ws://localhost:8181) | v Yerel Yazici Ajan (Bilgisayarinizda calisan program) | +---------+-----------+ | | | Yazici Kaydet Varsayilan Dialogu Dialogu Uygulama
Nasil Calisir? Guacamole uzerinden bir dosya indirdiginizde veya yazdir komutunu kullandiginizda, sistem dosyayi otomatik olarak bilgisayarinizdaki ajana gonderir. PDF dosyalari icin yazici secim ekrani, diger dosyalar icin "Farkli Kaydet" penceresi acilir.

2. Gereksinimler

Gereksinim Aciklama
Isletim Sistemi Windows 10 veya Windows 11 (64-bit)
Web Tarayici Google Chrome, Microsoft Edge veya Firefox (guncel surum)
Ag Erisimi Guacamole sunucusuna erisim: https://rguac.tdv.org:9443
Yonetici Yetkisi Kurulum icin bir kerelik yonetici (Administrator) yetkisi gereklidir
Port 8181 portu yerel bilgisayarda acik olmalidir
Not: .NET calisma zamani (runtime) kurulumu gerekmez. Program tum bagimliliklariyla birlikte tek dosya halinde paketlenmistir.

3. Kurulum Adimlari

3.1 MSI Dosyasini Edinin

1 Kurulum dosyasini indirin veya kopyalayin

IT biriminizden GuacamolePrintAgent.msi dosyasini edinin (yaklasik 65 MB). Dosyayi masaustunuze veya istediginiz bir klasore kaydedin.

3.2 Kurulumu Baslatin

2 MSI dosyasina cift tiklayin

GuacamolePrintAgent.msi dosyasina cift tiklayarak kurulumu baslatin.

3 Yonetici iznini onaylayin

Windows "Kullanici Hesabi Denetimi" (UAC) penceresi acilacaktir. "Evet" diyerek yonetici izni verin.

Onemli: "Hayir" derseniz kurulum yapilamaz. Program, guvenlik duvari kurallari ve Windows Defender istisnalari eklemek icin yonetici yetkisine ihtiyac duyar.
4 Kurulum tamamlandi

Kurulum otomatik olarak tamamlanir. Asagidaki islemler arka planda gerceklesir:

Islem Aciklama
Dosya kopyalama C:\Program Files\GuacamolePrintAgent\ klasorune kurulum
Guvenlik Duvari Port 8181 icin kural eklenir
Windows Defender Program icin istisna eklenir
Otomatik baslatma Her Windows girisi otomatik calisir
Ajan baslatma Program hemen arka planda baslar
Kurulum tamamlandi! Program arka planda calismaya basladi. Bilgisayarinizi her actiginizda otomatik olarak baslar. Herhangi bir sey yapmaniz gerekmez.

3.3 Sessiz Kurulum (IT Yoneticileri Icin)

Toplu dagitim icin komut satirindan sessiz kurulum:

msiexec /i GuacamolePrintAgent.msi /qn

Kurulum sonrasi ajanin hemen baslatilmasi icin:

wscript.exe "C:\Program Files\GuacamolePrintAgent\StartHidden.vbs"

4. Guacamole'a Giris (OIDC)

1 Tarayicida Guacamole adresini acin

Web tarayicinizda asagidaki adresi acin:

https://rguac.tdv.org:9443/guacamole/#/

Guacamole sizi otomatik olarak kurumsal ADFS giris sayfasina yonlendirecektir.

TDV Giris Portali - Kurumsal e-posta adresinizi girin

2 Kurumsal sifrenizi girin

ADFS sayfasindan sonra Turkiye Diyanet Vakfi kimlik dogrulama sayfasina yonlendirilirsiniz. Kurumsal sifrenizi girerek oturum acin.

TDV kimlik dogrulama sayfasi - Sifrenizi girin

ADFS Nedir? Kurumunuzun merkezi kimlik dogrulama sistemidir (Active Directory Federation Services). Guacamole adresi acildiginda otomatik olarak bu giris sayfasina yonlendirilirsiniz. Basarili giris sonrasi Guacamole anasayfasina otomatik doneceksiniz.
3 Anasayfa ve Baglantilari Gorun

Basarili giris sonrasi Guacamole anasayfasini goreceksiniz. Burada size tanimli RDP baglantilari listelenir.

Guacamole anasayfasi - Baglanti listesi ve sol altta yesil yazici ikonu

Yazici ikonu yesil! Sol alt kosede yesil yazici simgesi gorunuyorsa, yazici ajan bilgisayarinizda calisiyor ve baglanti basarili demektir.
4 RDP Baglantisina Tiklayin

Listeden istediginiz uzak masaustu baglantisina tiklayarak oturumu baslatin. RDP sunucusuna baglanmak icin sifrenizi girmeniz istenebilir.

RDP baglantisi sifre ekrani - Sifrenizi girip "Continue" tiklayin

5 Uzak Masaustunde Calisin

Baglanti kurulduktan sonra uzak masaustu uygulamalarinizi kullanabilirsiniz. Dosya indirme ve yazdirma islemleri otomatik olarak yerel bilgisayariniza iletilir.

Uzak masaustunde uygulama ekrani (Nebim V3)

5. Yazdirma ve Dosya Indirme

5.1 Yazici Ajan Durumu

RDP oturumu acildiginda, tarayici penceresinin sol alt kosesinde bir yazici simgesi goreceksiniz. Bu simge, yazici ajaninin durumunu gosterir:

Bagli (Yesil)

Ajan calisiyor, yazdirma hazir

Bagli Degil (Gri)

Ajan calismiyior veya baglanti yok

Asagidaki ekran goruntusunde sol alt kosedeki yesil yazici ikonu gorulebilir:

Sol alt kosedeki yesil yazici ikonu - ajan bagli ve hazir

Simge gri ise: Yazici ajan bilgisayarinizda calismiyior olabilir. "Sorun Giderme" bolumune bakin.

6. Kurulum Dogrulama

Kurulumun basarili oldugundan emin olmak icin asagidaki kontrolleri yapin:

6.1 Saglik Kontrolu (Health Check)

1 Tarayicida saglik kontrolu yapin

Web tarayicinizda asagidaki adresi acin:

http://localhost:8181/health

Eger ajan calisiyor ise bir yanit goreceksiniz. Sayfa acilmiyorsa ajan calismiyior demektir.

6.2 Gorev Yoneticisinden Kontrol

2 Gorev Yoneticisini acin

Ctrl + Shift + Esc tuslariyla Gorev Yoneticisini acin.

"Ayrintilar" sekmesinde GuacamolePrintAgent.exe islemini arayin.

Islem listede gorunuyorsa: Ajan dogru bir sekilde calisiyor.

6.3 Tarayici Konsolundan Kontrol

3 Tarayici konsolunu kontrol edin

Guacamole sayfasinda F12 tusuna basin, "Console" sekmesine gecin. Asagidaki mesajlari gormelisiniz:

PRINT INTERCEPTION v9.0
Print agent CONNECTED

7. Sorun Giderme

7.1 Yazici ikonu gri (baglanti yok)

? Ajan calismiyior olabilir

Cozum:

  1. Gorev Yoneticisinde GuacamolePrintAgent.exe islemini kontrol edin
  2. Islem yoksa, Baslat menusu arama cubuguna StartHidden yazip calistirin: 
    C:\Program Files\GuacamolePrintAgent\StartHidden.vbs
  3. Hala calismiyorsa, MSI dosyasini tekrar calistirarak "Onar" secenegini kullanin

7.2 Yazdir komutu calismiyior

? Dosya iletilmiyior

Kontrol Edin:

  1. Sol alt kosedeki yazici ikonu yesil mi?
  2. Tarayicida F12 → Console sekmesinde hata var mi?
  3. Sayfayi Ctrl + Shift + R ile yenileyin

7.3 Yazici secim ekrani gelmiyor

? Dialog penceresi arka planda kalmis olabilir

Cozum:

  1. Gorev cubugunda GuacamolePrintAgent simgesine tiklayin
  2. Alt + Tab ile pencereler arasi gecis yapin
  3. Hala gelmiyorsa, ajani yeniden baslatin: Gorev Yoneticisinde islemi sonlandirin, ardindan StartHidden.vbs calistirin

7.4 "Baglanti reddedildi" hatasi

? Guvenlik duvari port 8181'i engelliyor olabilir

Cozum:

  1. Windows Guvenlik Duvari → Gelen Kurallar icinde "Guacamole Print Agent" kuralini kontrol edin
  2. Kural yoksa, komut satirindan ekleyin: 
    netsh advfirewall firewall add rule name="Guacamole Print Agent" dir=in action=allow protocol=TCP localport=8181

7.5 Windows Defender programi engelliyor

? Defender istisnasi eklenmemis olabilir

Cozum: Asagidaki dosyayi yonetici olarak calistirin:

"C:\Program Files\GuacamolePrintAgent\DefenderSetup.bat"

8. Programi Kaldirma

8.1 Windows Ayarlarindan Kaldirma

1 Ayarlar → Uygulamalar → Yuklu Uygulamalar
  1. Win + I tuslariyla Ayarlar'i acin
  2. Uygulamalar → Yuklu uygulamalar bolumune gidin
  3. "Guacamole Print Agent" uygulamasini bulun
  4. Uc nokta menusune tiklayip "Kaldir" secin
  5. Yonetici iznini onaylayin

8.2 Komut Satirindan Kaldirma

msiexec /x GuacamolePrintAgent.msi /qn
Kaldirma Islemleri: Program dosyalari, guvenlik duvari kurali, Windows Defender istisnasi ve otomatik baslatma kaydi otomatik olarak temizlenir.
